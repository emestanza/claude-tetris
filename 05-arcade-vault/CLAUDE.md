# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Scope of this directory

`05-arcade-vault/` is a sub-project inside the Tetris repo (`/var/www/claude-tetris`). The root `CLAUDE.md` describes the vanilla-JS Tetris game and does **not** apply here: this is a Next.js app with a `package.json`, TypeScript, ESLint and Tailwind. Sibling `04-arkanoid/` is a separate vanilla-JS game.

Arcade Vault is meant to be a platform for playing games online and competing for the highest score (see `README.md`, written in Spanish). It is currently an untouched `create-next-app` scaffold (`app/page.tsx`, default metadata and `public/` assets are still the boilerplate), so there is little application code yet.

No test runner is configured. Type-check with `npx tsc --noEmit`.

## Next.js version caveat

This uses Next.js 16.4.2 / React 19.3, which has breaking changes relative to common training data. `AGENTS.md` (auto-generated by `next dev`) requires reading the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next.js code, and heeding deprecation notices. Don't remove that block from `AGENTS.md`; `next dev` re-adds it.

## Architecture / config notes

- App Router only (`app/`); path alias `@/*` maps to the project root.
- `next.config.ts` enables non-default options that affect how pages must be written: `cacheComponents: true`, `partialPrefetching: true`, and `experimental.agentFeedback`. Check the docs for these before relying on default caching/rendering behavior.
- Tailwind v4 is wired through Turbopack's `rules` for `*.css` (`@tailwindcss/turbopack` loader) rather than a PostCSS config; theme tokens live in `app/globals.css` under `@theme inline`.
- Typed route props such as `LayoutProps<"/">` are used in `app/layout.tsx` (globally generated types, no import needed).
